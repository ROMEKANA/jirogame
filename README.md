# JIROWOLF ルールメモ

このゲームは、Firebase Realtime Databaseで進行を同期するオンライン人狼です。  
「会話でだます」だけじゃなく、ちょっとクセのある独自役職で盤面が毎回かなり変わります。

## ざっくり流れ

1. 参加者が部屋に入り、役職を配布
2. ゲーム開始で 0日目の夜 からスタート
3. 夜: 各自が行動先を選ぶ
4. 昼: 話し合いと投票
5. 勝敗がつくまで 3 と 4 を繰り返す

## 勝利条件

- 市民陣営勝利: 生存中の人狼が 0 人になったとき
- 人狼陣営勝利: 生存人狼数が、生存非人狼数以上になったとき
- てるてる陣営勝利: 昼の処刑で てるてる が処刑されたとき

## 得点

- 市民陣営が勝利: 市民陣営の各プレイヤー +3
- 人狼陣営が勝利: 人狼陣営の各プレイヤー +5
- てるてる陣営が勝利: てるてる陣営の各プレイヤー +7

## 役職一覧（この実装での動き）

- 市民（市民陣営）
	- 特殊能力なし。昼の議論と投票が主戦場。
- 人狼（人狼陣営）
	- 夜に襲撃先を選ぶ。複数人狼の投票で襲撃先が決まる。
- 占い師（市民陣営）
	- 夜に選んだ相手の判定を翌昼に確認できる（人狼かどうか）。
- 狂人（人狼陣営）
	- 陣営は人狼側。夜の襲撃能力は持たない。
- 騎士（市民陣営）
	- 夜に選んだ相手を護衛。襲撃対象が護衛されていると襲撃失敗。
- 勘違い占い師（市民陣営）
	- 表示上は占い師。結果はランダム判定で正確ではない。
- 社畜（市民陣営）
	- 夜の襲撃では直接死亡しない。
	- ただし、人狼の襲撃先と同じ相手を選んでいると巻き込まれて死亡。
- 霊媒師（市民陣営）
	- 処刑された人の判定を確認できる（条件を満たす昼のみ表示）。
- てるてる（てるてる陣営）
	- 昼に処刑されると即勝利。
- 勘違い人狼（市民陣営）
	- 表示上は人狼。行動入力も人狼風だが、実際の人狼襲撃集計には含まれない。
- 逃亡者（市民陣営）
	- 夜の襲撃では直接死亡しない。
	- 選んだ相手が人狼だと死亡。
	- さらに、人狼の襲撃先と同じ相手を選んでいても巻き込まれて死亡。

## 投票と同数時の処理

### 夜（人狼の襲撃先決定）

- 人狼の投票を集計し、最多得票を襲撃対象にする
- 同数になった場合
	- 設定でランダム襲撃がONなら、同数候補からランダム1人
	- ランダム襲撃がOFFなら再投票
	- 再投票後も同数ならランダム1人

### 昼（処刑先決定）

- 生存者全員の投票を集計して最多得票を処刑
- 同数になった場合
	- 再投票設定がONなら1回だけ再投票
	- それでも同数なら
		- 処刑スキップ設定がON: 処刑なし
		- OFF: 同数候補からランダム処刑

## 初期設定（デフォルト）

- 初夜の襲撃: OFF
- 同数投票時に再投票: ON
- 夜の同数投票時にランダム襲撃: ON
- 昼の同数投票時に処刑スキップ: ON
- 議論時間: 3分
- 初夜占い: ON
- 初日の処刑: OFF
- 死亡時の役職公開: OFF

## 参加時の注意

- ゲーム中に新規参加はできません
- プレイヤー名に `.#$/[]` は使えません（Firebaseキー制約）
- 役職が未配布のプレイヤーがいると開始できません

## このゲームの面白ポイント

- 「勘違い系役職」で情報がノイズ化して、推理が揺れる
- 社畜・逃亡者の巻き込み死で、夜の結果が読みづらくなる
- 同数時ルールを設定で変えるだけで、村の空気が激変する

短期決戦でも、じわじわ心理戦でも遊べる設計です。  
とりあえず一戦やると、だいたい誰かが「その仕様かよ！」ってなります。

## 表示されないとき

- いったんリロールしてみてください。
- 人数が多い時の占い先の表示、再入室時の表示は遅れてしまうことがあります。
- 表示されなかった瞬間に叫ぶ行為、バグを装って偽カミングアウトをする行為は推奨いたしません。

# Firebase無料プラン（Spark）運用による注意

- 同時接続数、通信量、保存量には上限があります。参加人数が多い部屋を長時間運用すると制限に届くことがあります。
- 制限に達すると、読み書きが遅くなったり、更新に失敗したり、接続が不安定に見えることがあります。
- 運用前に Firebase コンソールで使用量（Realtime Database の接続数・ダウンロード量・保存量）を定期確認してください。
- 連続アクセスや再接続が増えると使用量も増えます。表示更新の連打や無駄なリロードは控えるのがおすすめです。
- 公開運用する場合は、Realtime Database ルールを必ず見直してください（匿名で書き込み放題にしない）。

- バグなどがあれば、https://github.com/ROMEKANA/jirogame/issuesまで。
